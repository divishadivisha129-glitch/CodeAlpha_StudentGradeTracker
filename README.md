# Student Grade Tracker

## Project Description
This is a Java-based Student Grade Tracker.

## Features
- Enter student names and marks.
- Calculate average marks.
- Find highest marks.
- Find lowest marks.
- Display student grade reports.

## Technologies Used
- Java
- Scanner
- Arrays
- Loops
- Conditional Statements

## How to Run
1. Download StudentGradeTracker.java.
2. Compile using `javac StudentGradeTracker.java'
3. Run using `java StudentGradeTracker'
